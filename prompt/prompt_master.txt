## CONTEXTO DO PROJETO
<context>
Estou criando um app chamado **SuperCRM**, que funciona como uma extensão operacional do meu sistema corporativo.

Atualmente, o sistema corporativo possui funcionalidades limitadas de CRM, o que dificulta o acompanhamento, histórico e operacionalização de propostas comerciais.

Fluxo central:
1. Exporto periodicamente um conjunto de propostas do sistema corporativo;
2. Importo essas propostas no SuperCRM;
3. No SuperCRM, realizo:
   - Atualizações de campos específicos;
   - Registro de atividades;
   - Histórico operacional;
   - Apoio à gestão do pipeline;
4. O sistema corporativo continua sendo a **fonte oficial** para consulta executiva;
5. As propostas que sofreram alterações em campos controlados são identificadas;
6. Essas alterações são replicadas manualmente no sistema corporativo;
7. O ciclo é reiniciado com nova exportação/importação.

O SuperCRM **não substitui** o sistema corporativo; ele atua como uma camada operacional e analítica intermediária.
</context>
